# map/ — керування картою

## Структура

```
map/
  MapManager.java          ← координатор усіх зон/точок однієї гри
  zones/
    ZoneArchetype.java             ← база: просторова зона (центр+радіус)
    ManiacSpawnZoneArchetype.java
    EscapeZoneArchetype.java
    ItemSpawnZoneArchetype.java
    PointOfInterestArchetype.java  ← база: точковий об'єкт (один блок)
    GeneratorPoi.java
    ExitPoi.java
```

## Дві різні речі: зони й точки

- **Зона** (`ZoneArchetype`) — просторова область (центр + радіус),
  перевіряється "чи гравець УСЕРЕДИНІ". Спавн маньяка, спавн
  виживших, зона втечі — усі мають однакову форму.
- **Точка інтересу** (`PointOfInterestArchetype`) — один конкретний
  блок з прогресом (0-100%), перевіряється "хто з ним ВЗАЄМОДІЄ".
  Генератор, двері виходу.

У v3 (`game/ManiacSpawnZone.java`, `EscapeZone.java`,
`ItemSpawnZone.java`) три зони дублювали одна й ту саму функцію
пошуку випадкової поверхневої точки і перевірку "гравець
всередині" — кожна своєю копією. Тепер це один метод у
`ZoneArchetype`, успадкований усіма трьома.

## MapManager — навіщо окремо від ManiacGameManager

`ManiacGameManager` (лишається як є) відповідає за ХІД ГРИ: хто
маньяк, скільки часу лишилось, коли гра закінчується. `MapManager`
відповідає за САМУ КАРТУ: де стоять генератори, де зона втечі. Це
розділення означає, що зміна структури карти (додати новий тип
зони) не вимагає лізти в логіку ходу гри, і навпаки.

## Як додати новий тип зони/точки

- Нова просторова зона → `extends ZoneArchetype`, додати список
  і методи `addXxx()`/`xxx()` у `MapManager`.
- Нова точка інтересу → `extends PointOfInterestArchetype`,
  реалізувати лише `ticksNeeded()`.
