# registry — Forge-реєстрації

`ModItems`, `ModBlocks`, `ModEntityTypes`, `ModSounds`, `ModCreativeTab`.

Тут лише механіка `DeferredRegister`. Самі СПИСКИ живуть у своїх
модулях — наприклад, перелік предметів у `items/ItemRegistry`.

Причина: у v3 список предметів (`ModItems`) і список творчої вкладки
(`ModCreativeTab`) були двома незалежними переліками, які треба було
тримати синхронними вручну. Тепер обидва читають `ItemRegistry`, тож
предмет не може існувати в грі й бути відсутнім у вкладці.

## Додати предмет

Один рядок в `items/ItemRegistry`. Усе інше — саме.

## Додати звук

Константа в `ModSounds` **разом із** файлом
`assets/maniacmod/sounds/<name>.ogg` і записом у `sounds.json`.
Реєстрація без файлу не падає — вона дає тишу, і причину потім довго
шукати.
