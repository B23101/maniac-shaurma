# traps/ — пастки маньяка

## Що тут

- **TrapArchetype** — абстрактний базовий клас. Спільні дані
  (кулдаун розміщення) і контракт (`applyEffect`, `shouldTrigger`).
- **TrapPlacementRules** — спільні правила розміщення ("не під
  гравцем", "не ближче 3 блоків до гравця") — застосовуються
  однаково до всіх 4 типів пасток, не дублюються в кожному класі.
- **TrapRegistry** — список усіх пасток гри.
- **BearTrapArchetype** (Капкан), **ElectricWireArchetype** (Щіпи),
  **RopeBindArchetype** (Мотузка), **MineArchetype** (Розтяжка) —
  конкретні пастки, дані перенесені 1:1 з v3 (кулдауни з
  `game/BearTrapState.java`, `ElectricWireState.java`,
  `RopeBindState.java`, `MineState.java`).

## Як додати нову пастку

1. Новий клас `extends TrapArchetype` у цьому пакеті.
2. Один рядок `register(new NewTrapArchetype());` у `TrapRegistry`.
3. Правила розміщення (`TrapPlacementRules`) підхоплюються
   автоматично — новій пастці не треба їх переписувати.

## Чому TrapPlacementRules окремо від TrapArchetype

Правила розміщення — властивість МІСЦЯ (де стоїть гравець), а не
властивість конкретного типу пастки. Усі 4 пастки мають однакові
обмеження "не під гравцем / не ближче 3 блоків" — тримати цю
перевірку в одному класі означає, що зміна правила (наприклад,
збільшити мінімальну відстань до 5 блоків) — одна правка, а не
чотири.
