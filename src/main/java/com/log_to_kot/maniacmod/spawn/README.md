# spawn — розкидання по карті

Карта 300 × 300 блоків із заздалегідь розміченими точками.

## Файли

- `SpawnPointKind` — SURVIVOR / MANIAC / ITEM / GENERATOR / EXIT
- `SpawnPoint` — одна точка: позиція, поворот, вид, власник
- `SpawnRules` — усі числа в одному місці
- `SpawnPlanner` — будує план розкидання

## Правила

| Правило | Значення | Послаблюється? |
|---|---|---|
| Одна точка = один гравець | — | **ніколи** |
| Виживий ↔ маньяк | ≥ 60 бл | так, до 6 кроків по ×0.85 |
| Виживий ↔ виживий | ≥ 20 бл | так, аналогічно |
| Задіяних ITEM-точок | ≈ 60% | — |

Точки маньяка прив'язані до `ownerId` — id архетипу. У Чакі і
Слендермена різні стартові локації.

## Порядок

1. `plan(...)` рахує все в пам'яті.
2. Не вдалося — `SpawnPlanFailure`, **нікого ще не зрушено**.
3. Вдалося — застосовуємо план і телепортуємо.

Інверсія цього порядку і була джерелом «половина команди на карті,
половина в лобі».

## Ще не зроблено

- Команди розмітки (`/maniac addpoint …`) і збереження у конфіг світу
- Валідація, що точка всередині 300×300 (`SpawnPlanner.isInsideMap`)
- Перевірка, що під точкою тверда поверхня
