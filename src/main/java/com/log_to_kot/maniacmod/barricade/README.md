# barricade — закриті зони (дошки, які ламають ломом)

## Два види барикад

| | Фіксована | Гнучка |
|---|---|---|
| Що це | подвійний блок `maniacmod:boards` на дверях/стіні | довільні дошки (земля, стіна, діагональ) |
| Рендер | звичайний блок (`blockstates/boards.json`) | `BarricadeEntity` + `client/barricade/PlankRenderer` |
| Колізія | фізичний блок, обидві половини | невидимі `BarricadeColliderEntity` уздовж дошок |
| Реєстрація | `/maniac barricade door` (дивлячись на блок) | `/maniac barricade create [ім'я]` (без прицілювання) |
| Розмітка | `FixedBarricade` | `FlexibleBarricade` (дошки = `BoardSpec`) |

Обидві зберігаються в `barricade_layout.yml` (`config/BarricadeConfigs`).

## Гра — міні-гра «Зняти барикаду»
ПКМ ломом по барикаді (будь-якій її дошці) відкриває екран `BarricadeGameScreen`: «дірка» у формі
барикади й у ній ТІ САМІ дошки, що у світі (розмір, поворот, текстура блока). На кожній дошці по
цвяху з кожного кінця — **цвяхів удвічі більше, ніж дощок** (фіксована двері: 8 дощок / 16 цвяхів).

- Навести на цвях і **затиснути ЛКМ (або Пробіл)** — лом тягне цвях; скрип росте в тоні, тріски, шкала-кільце.
  Відпустив — цвях осідає назад (`RELAX_*` у `BarricadeModule`).
- Вийшов один цвях — дошка провисає на другому; вийшли обидва — падає (звук `board_fall`).
- Цвях під іншою дошкою закритий (порядок малювання = глибина): знімай зверху вниз.
- Зняті всі дошки → барикада розвалюється (`barricade_collapse`).
- Лом зношується за КОЖЕН витягнутий цвях (`crowbarWearPerNailPercent`, за замовчуванням 2%), а не за всю
  барикаду; зламався посеред роботи — гра для цього гравця закривається.
- Серцебиття (страх) прискорює тягання цвяха (`heartbeatSpeedBonus`), але в меню міні-гри швидкість не показується; скрип/виліт/падіння грає СЕРВЕР у світі — чує й маньяк.
- Один цвях тягне один гравець; кілька виживих можуть працювати над однією барикадою паралельно.
- Esc/відхід — гра закривається, прогрес (витягнуті й розхитані цвяхи) лишається на сервері до кінця фази.
- Туторіал із живим демо показується при першому відкритті, далі — клавіша H або кнопка «? Довідка».

Архітектура: `BarricadeScene` (common) — плоска сцена: фіксована береться з `boards_lower/upper.json`,
гнучка — проєкція `BoardSpec`; сервер знає лише кількість дощок/цвяхів. Мережа: S2C
`BarricadeGameOpenPacket` / `BarricadeNailPacket` / `BarricadeGameClosePacket`, C2S
`BarricadeNailHoldPacket` (лише на зміну: «тримаю №N» / «відпустив») і `BarricadeGameExitPacket`.
Сервер — джерело правди (`BarricadeModule.Game`): клієнт лише показує й шле наміри.
Ту саму сцену малює `client/barricade/BarricadeSceneView` (і гру, і демо).
Ламати може лише виживий у ігровій фазі (`BarricadeModule.mayInteract`); без лома — «Потрібен лом».
У LOBBY, SCATTER і ROLE_REVEAL `restoreAll` виставляє розмітку у світ і зачиняє ванільні двері за фіксованими дошками; посеред матчу синхронізації немає.

## Що видно у світі
- **Гнучка барикада**: сервер публікує стан цвяхів у `BarricadeEntity` (синхронізовані дані `STATE`), клієнт
  малює за ним кожну дошку через `client/barricade/BoardAnimator`: розхитаний цвях відводить кінець від поверхні,
  вийшов один цвях — дошка провисає на другому (пружна анімація), вийшли обидва — падає на підлогу й лежить там,
  доки не розвалиться вся барикада. Упала дошка більше не ловить приціл лома. Колізія НЕ змінюється: прохід
  відкривається лише коли знято всю барикаду.
- **Обидва види**: над барикадою висить підпис «Дошок лишилось / Цвяхів лишилось» (ванільний `TextDisplay`,
  позначений тегом `maniac_barricade_label`); з'являється при першому відкритті міні-гри, оновлюється при
  зміні чисел, зникає разом із грою. Фіксована барикада (блок) власної сутності не має, тому її дошки у
  світі не падають — лише підпис, частинки й звук.
- Прогрес міні-гри живе, доки матч в ігрових фазах (HUNT → POWERED → … не скидає його); при виході з
  ігрових фаз гру закрито, а при поверненні в LOBBY/SCATTER дошки знову стоять (`restoreAll`).

## Режим будування (адмін)
`/maniac barricade build` → ПКМ по поверхні: точка 1, точка 2 — дошка. Текстура = блок у руці.
ПКМ іншим блоком по готовій дошці → нова текстура ВСІМ дошкам буфера. Shift+ПКМ по дошці —
прибрати її; без дошки — скасувати першу точку. Буфер видно лише адміну (`BarricadeBuildStatePacket`),
з прев'ю наступної дошки. `create` → зареєстровано, текстуру вже не змінити: лише `remove` і заново.

## Межі
- Нормаль дошки = «на гравця» (`BarricadeGeometry.faceNormal`) і зберігається в `BoardSpec`.
- Розміри дошки — константи `BarricadeGeometry` (клієнт малює сам); числа адміна — `barricades.yml`.
- Колізія — ланцюжок кубиків 0.4 (AABB осьовий); дошка на підлозі нижча за крок гравця й
  проходиться зверху.
