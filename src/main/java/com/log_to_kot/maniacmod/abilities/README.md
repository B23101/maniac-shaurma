# abilities/ — здібності маньяків (плагінна система)

## Що тут

- **Ability** — інтерфейс: `id()`, `cooldownTicks()`, `activate(player)`.
- **AbstractAbility** — базова реалізація зі спільним обліком
  кулдауну per-гравець. Конкретна здібність перевизначає лише
  `doActivate(...)` — сам ігровий ефект.
- **DashAbility** — приклад-заглушка, показує форму реальної
  здібності.

## Навіщо окремо від maniacs/

Здібність — НЕ метод усередині конкретного маньяка. Це самостійний
плагін, який `ManiacArchetype.abilities()` підключає списком.
Причина: одна й та сама здібність (ривок, невидимість, телепорт до
цілі) може знадобитись кільком різним маньякам одночасно — без
цього поділу довелось би копіювати логіку ривка в кожен клас
маньяка, що його використовує.

## Як додати нову здібність

1. Новий клас у цьому пакеті, `extends AbstractAbility` (або
   `implements Ability` напряму, якщо власний облік кулдауну не
   підходить).
2. Реалізувати `id()` і `doActivate(ServerPlayer)`.
3. Підключити до потрібного маньяка: у `ManiacArchetype`-підкласі
   додати екземпляр у список, що повертає `abilities()`.

Жодних правок у `ManiacGameManager` чи інших маньяках не потрібно —
HUD і мережевий шар (кулдаун-оверлей) читають список здібностей
через `Ability.id()`/`cooldownTicks()` узагальнено.
