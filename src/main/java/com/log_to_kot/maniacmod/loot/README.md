# loot — предмети на землі

Предмети на землі — власні сутності з geo-моделлю та окремою
анімацією, не ванільний `ItemEntity`.

## Файли

- `LootEntry` — запис таблиці: предмет, кількість, шанс
- `GroundItemPlacement` — де лежить і як повернутий

## Поворот

- `spinDegrees` — випадковий 0–360 навколо вертикалі
- `tiltDegrees` — завжди 0, щоб предмет лежав рівно

⚠ Яка саме вісь є «вертикаллю», залежить від орієнтації geo-моделі в
Blockbench. Якщо предмети лягають боком — значення міняються місцями
**в одному місці тут**, а не в кожному предметі окремо.

## Ще не зроблено

- Сутність `GroundItemEntity` + рендерер
- Таблиці луту по типах точок
- Прибирання лежачих предметів у фазі `RESET`
