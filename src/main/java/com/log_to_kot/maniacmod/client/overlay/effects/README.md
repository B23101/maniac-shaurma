# client/overlay/effects — екранні ефекти

Ця папка зараз порожня. Тут з'являться повноекранні/повторюючі
візуальні ефекти, прив'язані до СТАНУ гравця, а не до одноразової
події і не до постійного HUD-числа: віньєтка серцебиття (heartbeat
з `SurvivorVitalsPacket` — зараз лише число 0.0–1.0, малювання ще не
реалізоване), затемнення екрана при `UNCONSCIOUS`, тремтіння камери.

## Чому не `vitals/` і не `notify/`

- `overlay/vitals/` малює ЧИСЛО як HUD-елемент (бар хп, іконка стану)
  — статичний за формою, змінюється лише вміст.
- `overlay/effects/` — сам ЕФЕКТ на весь екран, що вмикається й
  вимикається залежно від порогу (наприклад heartbeat > 0.7 →
  віньєтка видима), а не завжди намальований елемент.
- `overlay/notify/` — щось, що з'явилось один раз і зникло; ефект
  тут триває, поки триває сам стан (не має власного `durationTicks`).

## Джерело даних

Ефекти НЕ отримують власного пакета. Вони читають `ClientMatchState`
(поля `heartbeat()`, `survivorState()`), які вже оновлюються з
`SurvivorVitalsPacket` через `ClientPacketHandler.onVitals(...)`.
Новий ефект — це новий клас тут, підписаний на вже наявні поля, а не
новий S2C-пакет. Якщо здається, що для ефекту бракує даних із
сервера — спершу перевір `s2c/vitals/`, чи цього поля там уже нема.
