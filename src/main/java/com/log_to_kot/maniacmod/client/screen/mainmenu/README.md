# client/screen/mainmenu — головне меню

`ManiacTitleScreen` замінює ванільний `TitleScreen`; підміну робить
`ManiacTitleInterceptor` (`ScreenEvent.Opening`) — тому вона ловить усі шляхи на
головне меню: старт гри, вихід зі світу, «Назад» зі списку серверів,
`ManiacEscMenuScreen.leaveGame()`. Ванільний екран не стає поточним ні на кадр.
Інтерсептор також робить те, що ванільний `setScreen` робить лише для
`instanceof TitleScreen`: вимикає F3 і чистить чат.

## Стиль
Той самий, що в `screen/esc/ManiacEscMenuScreen`: бренд із літерами, що падають і
стікають кров'ю, чіп (тут — версія мода), кнопки-«леза», друкований опис кнопки під
курсором, соцмережі. Єдина відмінність — фон: замість `HorrorBackdrop` (кров зверху,
віньєтка) тут картинка. Око й картку «ЗАВДАННЯ» не малюємо — вони потрібні лише в
матчі й закривали б картинку.

Помічники малювання (`slantFill`, `text`, `bounce`…) і посилання соцмереж свідомо
продубльовані з ESC-меню, щоб не чіпати його файл: змінюєш URL — міняй в обох місцях.

## Фон (`ManiacMainMenuBackground`)
Картинка їде **праворуч → ліворуч і назад** (як у снайперів): трикутна хвиля +
easeInOutQuad, 40 с на цикл, старт із лівого краю, зсув через `PoseStack.translate(float)`
(без «застрягань» на розворотах). Картинка масштабується по висоті екрана й завжди
щонайменше в 1.25 раза ширша за нього, тож рухається навіть не-панорама.

Файл: `assets/maniacmod/textures/gui/main_menu/background.png`
(зараз там заглушка 3200×1080 — підклади свою; найкраще ширше за 16:9, ~21:9 і більше).
Підміняється й ресурспаком. Немає файлу — меню малює темний градієнт.
Ліву колонку затемнює плавний градієнт до ~62% ширини — праворуч картинка видна.

## Кнопки
`buildButtons()`: Мережева гра (головна) · Одиночна гра · Налаштування · Моди · Вийти.
Нова кнопка = один `new Btn(...)` + два ключі в lang (`.title.*` і `.desc`).
Ключі: `maniacmod.title.*` (+ спільні `maniacmod.esc.brand.*`, `maniacmod.esc.settings*`,
`maniacmod.esc.social.*.tip`).

## Назва вікна
`CustomWindowTitle` знає про цей екран і показує «Маніяк — Головне меню».
