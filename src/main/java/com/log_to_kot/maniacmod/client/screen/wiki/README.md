# client/screen/wiki — вікі предметів (клавіша H, лише виживі)

Гравець-вижилий тримає предмет мода й тисне **H** → відкривається `ItemWikiScreen`:
ліворуч об'ємна модель предмета (та сама geo-модель з анімацією `idle`) на
«п'єдесталі» зі світлом, променями й іскрами; праворуч стаття, що друкується
літера за літерою. Закриття — **Esc** (або H, або плашка ESC).

## Файли

| Файл | Що робить |
|---|---|
| `ItemWikiOpener` | єдина точка входу: роль, кіно-вступ, предмет у руці → відкрити екран |
| `ItemWikiScreen` | сам екран: фон, 3D-вікно, заголовок, стаття, ввід |
| `ItemWikiModel3d` | малює предмет у GUI через `ItemRenderer`, сам центрує за `.geo.json` |

## Коли відкривається

- роль на клієнті — виживий (маньяк і глядач не відкривають, клавіша просто «з'їдається»);
- предмет у головній (потім другій) руці є в `ItemRegistry` у групі `SURVIVOR`;
- не йде кіно-вступ і не відкрите інше меню.

Екран сам закривається, якщо виживого збили з ніг або роль змінилась.
Гра на паузу НЕ ставиться (як `TrapChooseScreen`: пауза завісила б сервер).

## Додати статтю для нового предмета

Предмет зареєстровано в `ItemRegistry` (група SURVIVOR) → він уже відкривається по H.
У `lang/uk_ua.json` та `lang/en_us.json` додай ключі (`<id>` — id предмета):

```
item.maniacmod.<id>                    назва (вже є)
maniacmod.wiki.item.<id>.role          коротка роль («Лікування»)       — необов'язково
maniacmod.wiki.item.<id>.desc          опис
maniacmod.wiki.item.<id>.use           як користуватись                 — необов'язково
maniacmod.wiki.item.<id>.fact.1..8     «Назва|Значення»                 — необов'язково
maniacmod.wiki.item.<id>.tip           порада                           — необов'язково
```

Без `desc` покажеться «статті ще немає». Інших змін у коді не потрібно.
Мова — клієнтська; відсутній переклад Minecraft замінює англійським.

⚠ Числа в `fact.*` — це дефолти з `ConfigSchema` (сервер може їх змінити; на екрані
про це написано). Змінив дефолт у конфігу → онови й lang.

## Свідомо НЕ тут

Жодних пакетів і серверної логіки: вікі — суто клієнтський довідник, нічого не змінює
в матчі, тож правило «сервер перевіряє все заново» (AI_CODE_GUIDE §3.6) не застосовується.
Нових чисел-налаштувань теж немає (тривалості анімацій — константи оформлення UI,
як у `TrapChooseScreen`).
