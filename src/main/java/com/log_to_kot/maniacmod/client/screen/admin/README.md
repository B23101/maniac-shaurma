# client/screen/admin — адмін-панель

Ця папка зараз порожня. Тут з'явиться GUI-еквівалент команд
`/maniac` (`server/ManiacCommand.java`) — щоб не набирати команду
руками під час тестів/модерації матчу.

## Правило, яке треба перенести з `/maniac` НЕ порушуючи

`server/README.md` фіксує: одна гілка команди на всі види точок,
бо всі точки однієї форми (`SpawnPoint`). Екран має відображати той
самий принцип — один узагальнений UI-блок для розмітки точок
(`point add/list/clear`), а не окрему кнопку на кожен `SpawnPointKind`.
Новий вид точки не повинен вимагати нового елемента інтерфейсу,
так само як не вимагає нової гілки команди.

## Джерело даних / дій

- Дії адмін-панелі НЕ дублюють логіку `ManiacCommand` — панель шле
  ті самі C2S-наміри, що виконує команда (новий пакет у
  `c2s/intent/` або `c2s/selection/`, залежно від форми дії — див.
  таблицю категорій у `net/README.md`), сервер обробляє через
  `ServerPacketHandler`, а не напряму через `ManiacCommand`.
- Право доступу (чи гравець адмін) перевіряється на сервері при
  обробці пакета — так само, як `ServerPacketHandler` перевіряє роль
  для звичайних гравців. Клієнт лише ховає кнопку для неадміна;
  сервер це не довіряє клієнту.

## Категорія

`screen/`, бо це повноцінне меню з формами вводу, не HUD-накладка.
