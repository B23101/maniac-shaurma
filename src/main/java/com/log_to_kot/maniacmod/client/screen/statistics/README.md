# client/screen/statistics — підсумковий екран матчу

`MatchSummaryScreen` — ОДИН екран із вкладками (замінив `MatchResultScreen` + `MatchStatsScreen`). Стиль ESC-меню/tab-екрана: кутові дужки, заголовок капсом із роздільником, прямокутні бари; кольори — лише з `ManiacUiTheme`/`ManiacMenuTheme`. Прозорий: за панелями видно freecam зі `STATS_CAMERA` (`victory/StatsCameraModule`).
Відкривається з `ClientPacketHandler.onPhase(ENDING)` (після сцени перемоги — `VictoryClient.runWhenIdle`).

## Вкладки (←/→ або миша)
1. **Огляд** — результат, роль, час, генератори N з M, скільки втекло.
2. **Мій внесок** — рядки XP, рівень, ранг і смужка, власні лічильники.
3. **Учасники** — таблиця з головами (`PlayerFaceRenderer`): гравець, результат, скільки протримався. Свій рядок підсвічений.

## XP на краю екрана
Справа, на будь-якій вкладці: картка «ДОСВІД ЗА МАТЧ» (сума росте з кожним нарахуванням, ранг, рівень, смужка) і XP-плашки, що по черзі в'їжджають і виїжджають. «Новий рівень / ранг» лишається внизу колонки. Усе рахується на клієнті з `MatchRewardPacket` — сервер нічого окремо не шле.

## Ранги
`progression/Ranks` — ранг похідний від рівня (`XpCurve`), окремо не зберігається: 7 ступенів (Новачок → Легенда), у ступені дивізіони I–V. Емблема — `client/style/RankFx`. Назви — `maniacmod.rank.<id>`. Майбутній екран профілю читає ранг звідти ж.

## Акценти й анімація
Один акцент результату — тонка лінія під заголовком: срібло (виживші) або `BAR_FILL_DANGER` (маніяк). Жодної крові, глітчу, тряски, миготіння, циклічних ефектів. «Пропустити» домотує все до кінця й стає «Закрити» — єдиний спосіб пропуску.

## Дані
- `MatchSummaryPacket` — результат, час, роль, лічильники (широкомовно).
- `MatchRewardPacket` — особисті рядки XP + загальний XP до/після (`progression/MatchRewardService`, шлеться на вході в ENDING).
- Рівень: `progression/XpCurve` (рівень L закривається за `50 + 250·L` XP). XP зберігається в `<світ>/data/maniacmod/xp/<uuid>.json`.
- Розмір нагород — `game`-блок конфіга: `xpMatchComplete`, `xpWin`, `xpEscape`, `xpGenerators` (+`xpGeneratorsMinSeconds`), `xpRescue`, `xpManiacHooks`, `xpManiacDowns`. Кожна нагорода одноразова за матч.

Екран живе, поки триває ENDING (`endingSeconds`, за замовчуванням 10 с) — для повільнішої анімації збільш це значення.

## Профіль (див. `client/screen/profile`)
`ProfileScreen` — профіль гравця: розділи «Виживший» / «Маніяк», 3D-модель до пояса з банером (нік/назва маніяка, ранг, прогрес), карусель маніяків зі стрілками, статистика з анімованими іконками (`client/style/ProfileIcons`).
Входи: кнопка «Профіль» в ESC-меню; власна клавіша `ManiacKeybinds.PROFILE` (за замовчуванням E; лише лобі, творчий режим і спостерігач не чіпаються); лобі-підказка `overlay/hint/ProfileHintOverlay`.
Дані: сервер ведe `progression/profile/PlayerProfile` (`<світ>/data/maniacmod/profile/<uuid>.json`), оновлює `ProfileRecorder` на вході в ENDING; клієнт запитує `ProfileRequestPacket` → `ProfilePacket` (`ClientProfileState`). XP — окремі доріжки: виживий і кожен маніяк; `MatchRewardPacket.xpBefore/xpAfter` тепер XP доріжки ролі, зіграної в матчі. Стара спільна XP (`xp/<uuid>.json`) мігрує в XP виживого.
Новий маніяк з'являється в профілі сам (`ManiacRegistry`); його модель — `geo/entity/<id>.geo.json`.


**Ранги.** Кнопка «РАНГИ» (або `R`) у верхній смузі `ProfileScreen` відкриває панель з усіма ступенями: емблеми, діапазони рівнів, «ВИ ТУТ» на поточному, драбина-рейка з прогресом і смужка XP поточного рівня. Доріжка залежить від розділу (виживший / вибраний маніяк). Закривається `R`, `Esc` або кліком.

**Спільний прогрес, окремі ранги.** XP зберігається по ролях (`survivorXp` і `Maniac.xp`), але рівень рахується із суми `PlayerProfile.totalXp()` — він один на обидві ролі (і в профілі, і в «до/після» на екрані підсумків). Назви й вигляд рангів залежать від ролі: `Ranks.Role` (виживий — сріблясті, маніяк — багряні). У панелі «Ранги» драбину іншої ролі можна подивитись клавішами `1` / `2` / `Tab`.

**Чужий профіль.** У лобі ПКМ по іншому гравцеві (`ClientInputHandler.onPlayerProfileInteract`) відкриває `ProfileScreen(parent, uuid, name)`. Клієнт шле `ProfileRequestPacket(target)`; сервер віддає чужий профіль лише у фазі LOBBY і лише для гравця онлайн (`ProfilePacket` несе `ownerId`/`ownerName`; чужі профілі лежать у `ClientProfileState.other(uuid)`). Під прицілом на гравці в лобі з'являється підказка «ПКМ — профіль гравця» (`ProfileHintOverlay`).

**Статистика пасток.** `MatchStats.addTrap` ← `TrapModule` (поставлено — `finishPlacement`; жертв — капкан, дріт, мотузка, шипи, димова міна: раз на жертву/хмару) → `MatchSummaryPacket.Entry.traps` → `ProfileRecorder` → `PlayerProfile.Maniac.traps` (по id пастки). У розділі «Маніяк» під героєм — смужка «Пастки»: клітинка на кожну пастку маніяка (`ManiacArchetype.traps()`), «поставлено / жертв».

**Підказки.** Наведи на плитку або клітинку пастки — з'явиться опис, що саме рахує лічильник (`maniacmod.profile.tip.s.*` / `.m.*`). Нова плитка = новий ключ `tip`.
