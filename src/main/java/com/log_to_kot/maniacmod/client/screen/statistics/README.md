# client/screen/statistics — підсумковий екран матчу

## Статус: реалізовано (базовий склад)

`MatchResultScreen` — звичайний ванільний `Screen`, відкривається з
`ClientPacketHandler.onPhase(GamePhase.ENDING)`. Показує три речі:
хто втік, хто загинув, ким був маньяк.

## Дані — без нового пакета

Читає `ClientMatchState.roster()`, той самий `RosterSyncPacket`, що й
`overlay/roster/TabRosterOverlay`. На момент входу в `ENDING`
(`aliveSurvivorCount() == 0`) кожен виживий уже ESCAPED або
ELIMINATED, тому останній отриманий roster — уже повний і остаточний
знімок матчу. Заводити окремий `MatchResultPacket` для тих самих
даних не було причини — детальне обґрунтування в docstring
`MatchResultScreen`.

## Якщо колись знадобляться дані, яких roster не несе

Кількість вбивств, час виживання, завершені об'єктиви за гравця —
цього зараз немає ніде. Якщо з'явиться вимога показати таке в цьому
екрані: це новий пакет у `matchstate/` (підсумок стану матчу), НЕ
розширення `RosterSyncPacket` (той несе поточний стан, не історію
матчу) — з тим самим обов'язковим "чому саме тут" у docstring, що і в
інших пакетах цієї категорії.

## Категорія

`screen/`, показується на подію завершення матчу (вхід у `ENDING`),
не постійно. Закривається гравцем вручну (кнопка "Готово" або
ванільний Escape) — сервер сам повертає всіх у `RESET` → `LOBBY`
незалежно від того, закритий екран чи ні.
