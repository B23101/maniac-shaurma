# client/screen/statistics — екран статистики

Ця папка зараз порожня. Тут з'явиться екран підсумків після матчу
(і, можливо, особиста статистика по акаунту — деталі ще не
затверджені в дизайн-документах).

## Головне правило (той самий урок, що й у roster)

`s2c/matchstate/RosterSyncPacket` (`net/s2c/matchstate/`, колишній
план з `s2c/roster/README.md`) сам передбачив цей випадок: якщо
з'явиться другий екран, якому потрібні ті самі дані "хто є хто в
матчі" — він ПІДПИСУЄТЬСЯ на вже наявний `RosterSyncPacket`, а не
отримує копію під новою назвою типу `StatisticsPacket`. Перш ніж
заводити новий пакет для цього екрана — перевір, чи не є потрібні
дані вже проекцією того, що везе `matchstate` чи `vitals`.

Якщо для підсумків справді потрібні дані, яких немає в жодному
наявному пакеті (кількість вбивств, час виживання, завершені
об'єктиви за гравця) — це новий пакет, і він іде в `matchstate/`
(підсумок стану матчу) з чіткою карткою "чому не розширення
RosterSyncPacket" в docstring, за зразком коментарів у вже існуючих
пакетах цієї категорії.

## Категорія

`screen/`, показується на подію завершення матчу, не постійно.
