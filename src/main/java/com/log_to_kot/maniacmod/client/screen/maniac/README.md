# client/screen/maniac — екран вибору маньяка

Ця папка зараз порожня. Тут з'явиться GUI-меню (`Screen`), де
маньяк обирає архетип на фазі вибору — клієнтська частина вже
існуючого потоку `c2s/selection/ManiacSelectPacket`.

## Джерело даних

- Список доступних архетипів — `ManiacRegistry` (той самий реєстр,
  що читає сервер у `ServerPacketHandler.onManiacSelected`). Екран
  не вигадує власний список — питає реєстр напряму, бо реєстр
  спільний для клієнта й сервера (не мережевий стан, а статичні дані
  мода, доступні на обох сторонах без пакета).
- Клік по варіанту → `ModNetwork.toServer(new ManiacSelectPacket(id))`
  — так само, як `ClientInputHandler` шле інші C2S-пакети.
- Коли показувати екран — читає `ClientMatchState.phase()` (фаза
  вибору маньяка) і `ClientMatchState.isManiac()` — глядачі й виживі
  цей екран не бачать.

## Категорія

Це `screen/`, не `overlay/`: гравець явно відкриває це меню (чи воно
відкривається примусово на фазі вибору) і взаємодіє з ним мишкою —
на відміну від `overlay/`, що малюється поверх геймплею без
перехоплення вводу.
