# client/screen/esc — кастомне ESC-меню

`ManiacEscMenuScreen` замінює ванільний `PauseScreen`; підміну робить
`ManiacEscInterceptor` (пріоритет LOW — щоб Esc у режимі розміщення
пастки та під час кіно-вступу, які скасовують подію раніше, працював як
працював).

## Стиль
Фон і кров — `style/HorrorBackdrop` + `style/BloodFx` (спільні з екраном
оцінок). Меню не ставить гру на паузу.

## Звуки
Відкриття і закриття меню (і підекранів) — БЕЗ звуку. Лишилися лише
наведення на кнопку, клік і попередження на «Відключитися».

## Повернення з підекранів
`new ManiacEscMenuScreen(true)` — меню без вступної анімації (літери не
падають вдруге, кнопки одразу активні). Так повертаються екрани оцінок,
«Скоро» і адмін-відгуків. `new ManiacEscMenuScreen()` — лише для першого
відкриття (`ManiacEscInterceptor`).

## Картка «ЗАВДАННЯ»
Справа внизу — те саме, що верхня картка Tab, але без зайвого: завдання за
роллю й фазою (ключі `maniacmod.tab.objective.<роль>.<фаза>` + `.sub`),
«N / M» і слоти генераторів (лише у HUNT/POWERED/FINALE), віхи, важливі
ролі. Фаза й роль окремо не дублюються — вони в чіпі під назвою.
Дані — `ClientMatchState.objectives()`, клієнт нічого не рахує.

## Кнопки
Адмін-відгуки відкриваються командою `/maniac reviews`, кнопки в меню нема.
Список збирається в `buildButtons()`: нова кнопка = один `new Btn(...)`
+ два ключі в lang (`.label`, `.desc`). Розкладка підлаштовується сама.
«Відключитися» озброюється першим натисканням (2.5 с) і виходить другим.

## Оцінки
Логіка як у снайперів — див. `screen/rating/ClientManiacRatingState`:
вихід перед першою оцінкою відкриває `ManiacRatingScreen`; кнопка
«Оцінити маньяків» з'являється в меню, коли гравець уже оцінював або
натиснув «пізніше». Дані — `net/s2c/rating`, `net/c2s/rating`,
сервер — `server/rating`. Адмін: `/maniac reviews`.

## Посилання соцмереж
Константи `URL_*` на початку `ManiacEscMenuScreen`.

## Око
Малюється в `renderEye` постовпчиково (без текстур). Живе: слідкує за
курсором, а без руху миші ~3 с блукає само; кліпає раз на ~7 с (інколи
двічі) і на кожен клік; верхня повіка опускається, коли око дивиться вниз.
Реакція на меню: над кнопкою — легкий примруж і ширша зіниця; коли
«Відключитися» озброєно — розплющується, зіниця звужується, склера й судини
червоніють. Геометрію повік рахують `lidTop/lidBot` — нову деталь малюй
через них, а не через власну формулу.
