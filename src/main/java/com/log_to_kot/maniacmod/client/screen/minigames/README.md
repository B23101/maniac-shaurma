# client/screen/minigames — міні-ігри

Ця папка зараз порожня. Заплановано на майбутнє (деталі механіки ще
не описані в `GAME_DESIGN.md` — цей README оновиться, коли дизайн
буде готовий). Скоріш за все це буде QTE-подібна взаємодія під час
ремонту генератора (`minigamesDone`/`minigamesTotal` у
`GeneratorProgressPacket` уже рахують кількість пройдених міні-ігор,
саму механіку одного проходження ще не реалізовано).

## Що вже узгоджено наперед

- Прогрес міні-гри НЕ отримує власного нового s2c-пакета "про кожен
  клік" — `net/README.md` вже забороняє слати щотік; сервер знає
  фінальний результат (успіх/провал), а сама механіка одного раунду
  QTE рахується і малюється ЛОКАЛЬНО на клієнті (як таймінг-бар), і
  лише результат (стагнація прогресу чи відкат) іде назад у
  `GeneratorProgressPacket`, що вже існує.
- Категорія `screen/`, а не `overlay/`, бо міні-гра перехоплює ввід
  (клік у потрібний момент), а не просто малюється поверх геймплею.

Коли дизайн буде готовий — цей README переписується з точним описом,
а не список "TODO кудись".
