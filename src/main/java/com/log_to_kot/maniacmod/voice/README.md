# Голосовий шар (Simple Voice Chat)

Модуль інтеграції з Simple Voice Chat (SVC): «жахливий» голос маньяка,
тиша на технічних фазах і спільний ефір без відстані на `ENDING`.

SVC **опційний**. Мод збирається лише проти `voicechat-api` (`compileOnly`):
якщо в гравця SVC немає — голосова частина просто не активується, решта
мода працює як звичайно.

---

## 1. Файли модуля

| Файл | Роль |
|---|---|
| `ManiacVoicePlugin` | точка входу SVC (`@ForgeVoicechatPlugin` + `META-INF/services`) |
| `ManiacVoiceModule` | клієнтський стан DSP-ефекту (activate/deactivate/`onClientSound`) |
| `VoiceActivation` | клієнтський місток «роль + фаза → ефект» |
| `ManiacVoiceProfile` | числа пресетів (`DEMON`, `TITAN`, `BATMAN`, `NEUTRAL`) |
| `dsp/ManiacVoiceChain` | спрощений DSP-ланцюжок (див. §3) |
| `dsp/*` | портований чисті Java DSP (див. §6, ліцензія) |
| `ServerVoiceSilenceModule` | серверна тиша через персональні `ISOLATED`-групи |
| `VoiceSilencePhaseModule` | `PhaseListener` для тиші |
| `VoiceEndingBroadcastModule` | серверний спільний (непозиційний) ефір |
| `VoiceEndingPhaseModule` | `PhaseListener` для `ENDING` |
| `VoiceRuntime` | серверна звʼязка порядку ініціалізації + cleanup |

## 2. Що відбувається у фазах

| Фаза | Голос |
|---|---|
| `LOBBY` | звичайний (позиційний) |
| `CINEMATIC` | тиша |
| `SCATTER` | тиша |
| `ROLE_REVEAL` | тиша для всіх; маньяк уже має свій ефект у своєму мікрофоні |
| `HUNT` | звичайний позиційний |
| `POWERED` | звичайний позиційний |
| `FINALE` | звичайний позиційний |
| `ENDING` | **спільний ефір без обмеження відстані** для всіх учасників |
| `RESET` | тиша |

Тиша реалізована **серверними групами**: кожному гравцю на тихій фазі
призначається його власна порожня `ISOLATED`-група (він нікого не чує, і
його ніхто не чує). Групою керує тільки код (група `hidden`), гравець не
бачить жодного діалогу.

`ENDING` — протилежний за задумом режим: там на кожного учасника
створюється `StaticAudioChannel`, а живий мікрофонний пакет кожного
пересилається каналам усіх інших. Це дає спільний голос незалежно від
фізичної позиції (хтось у спостерігачах, хтось на місці втечі).

---

## 3. Ланцюжок голосу маньяка

```
NoiseGate → rumble high-pass (75 Гц) → VocalPitchShifter (pitch і формант ОКРЕМО)
→ DeEsser → ToneStack (low/mid/high EQ) → SubOctaveGenerator (growl)
→ waveshaping distortion → RoomReverb (crossfade) → output gain → SoftLimiter
```

Активація — виключно кодом (`VoiceActivation`), за роллю й фазою. У
модуля **немає власного UI**: гравцю нема чого крутити. Це і є механізм
«гра керує голосом, а не гравець».

Обробка йде на клієнті того, хто говорить, — у документованій точці SVC
`ClientSoundEvent`, ДО Opus-кодування й відправки на сервер.

## 4. Конфіг

Блок `voice` у `config/maniacmod/voice.yml`:

| Ключ | Дефолт | Значення |
|---|---|---|
| `enabled` | `true` | вмикати ефект взагалі |
| `profile` | `DEMON` | `DEMON` \| `TITAN` \| `BATMAN` |
| `strength` | `100` | сила ефекту 0..100 (0 — майже нейтрально, 100 — повний пресет) |

Конфіг читає клієнт. У singleplayer/LAN (інтегрований сервер) значення
спільні для клієнта й сервера. На **виділеному** сервері віддалені клієнти
бачать дефолти, бо `ManiacConfigs` ініціалізується лише на сервері;
синхронізацію налаштувань голосу на клієнт можна додати окремим пакетом,
якщо знадобиться (наразі не реалізовано свідомо, щоб не плодити зайвий
протокол без потреби).

## 5. Обмеження (чесно)

* **Приховання штатного HUD-індикатора SVC не реалізовано.** План
  спирався на `HudIconRenderEvent`/`NameTagIconRenderEvent`, але їх **немає**
  в SVC API версії, доступної для Forge 1.20.1 (2.5.x). Штатна іконка
  залишається. Якщо колись перейдете на SVC API з цими подіями — це
  додається в `ManiacVoicePlugin.registerEvents` кількома рядками.
* **Пріоритет обробників.** У цій версії SVC більший пріоритет виконується
  **раніше**. Щоб голос маньяка був фінальним, обробник
  `ClientSoundEvent` реєструється з **від'ємним** пріоритетом (`-1000`).
  Це перевірено по коду `EventBuilder.build()`, а не вгадано.
* **Сторонній voice-changer.** Якщо гравець сам поставить сторонній мод,
  що хукається на той самий `ClientSoundEvent`, він матиме доступ до того
  ж PCM. Серверний мод не має влади над чужим клієнтом — це так само поза
  зоною контролю, як X-ray текстур-пак. Голос маньяка завдяки низькому
  пріоритету перекриє раніший обробник, але не «забороняє» інші моди.
* **Групи SVC.** Щоб гравець не міг вручну створювати/приєднуватись до
  груп, виставте у `config/voicechat/voicechat-server.toml`:
  `groups_enabled = false`. Це офіційний серверний прапорець, коду в моді
  не потребує. Мод керує своїми тимчасовими групами програмно й під цю
  заборону не підпадає.
