# maniacs/ — маньяки

## Що тут

- **ManiacArchetype** — абстрактний базовий клас. Спільні дані
  (розмір, швидкість FOV, кулдаун атаки) і спільна логіка
  (наприклад майбутній модифікатор кулдауну для всіх маньяків
  одразу) лежать тут ОДИН раз.
- **ManiacRegistry** — список усіх маньяків гри. Єдине місце
  реєстрації.
- **ChuckyArchetype**, **SlendermanArchetype** — конкретні маньяки.
  Кожен лише передає свої числа в конструктор базового класу і
  перевизначає `weaponItem()` / `abilities()`. Жодної логіки
  атаки/спавну тут немає — вона в `ManiacArchetype` або в
  `ManiacGameManager` (диригент матчу).

## Як додати нового маньяка

1. Новий файл `PennywiseArchetype.java` у цьому пакеті,
   `extends ManiacArchetype`.
2. Один рядок `register(new PennywiseArchetype());` у
   `ManiacRegistry`.

Все — конфіг (`maniacTypeMode: RANDOM/FIXED`), меню вибору
персонажа і команда `/maniac settype` автоматично побачать нового
маньяка, бо вони читають список через `ManiacRegistry.all()`,
а не через hardcoded enum (як було у v3 `entity/ManiacType`).

## Здібності маньяків — див. `abilities/`

Активні здібності (ривок, телепорт, невидимість тощо) — НЕ методи
всередині Archetype-підкласу, а окремі класи в `abilities/`, які
Archetype лише підключає списком у `abilities()`. Це дозволяє
перевикористати одну й ту саму здібність між кількома маньяками
без копіювання коду.
