# Звуки кіно-вступу — заготовки

Жодного `.ogg` тут поки немає, і гра від цього не ламається: `IntroAudio`
перед кожним звуком перевіряє, чи є його ключ у `sounds.json`, і мовчить,
якщо нема. Щоб озвучити подію — покладіть файл у
`assets/maniacmod/sounds/` і додайте запис у `sounds.json`. Java міняти не треба.

| Ключ у sounds.json | Коли грає | Побажання |
|---|---|---|
| `intro_music` | Одночасно з першим затемненням; плавно гасне при фінальному розтемненні | Довгий трек (≥ 15 с), не loop. Наростання 1.6 с додає код |
| `intro_darken` | Старт затемнення (0 с) | Низький гул / «вдих» |
| `intro_blackout` | Екран повністю чорний, камера стартує (0.9 с) | Короткий глухий удар |
| `intro_camera_in` | Чорне зникає, з'їжджає letterbox (1.6 с) | Свіш/повітря |
| `intro_tip_swap` | Зміна поради (кожні 5 с) | Дуже тихий «тік» |
| `intro_riser` | За 0.6 с до фінального затемнення | Наростання |
| `intro_game_start` | Початок розтемнення разом із пробудженням | Удар/різкий вдих |

Приклад запису (категорія значення не має — гучністю керує код):

```json
"intro_blackout": { "sounds": [ "intro_blackout" ] },
"intro_music":    { "sounds": [ { "name": "intro_music", "stream": true } ] }
```

Музику рекомендується позначати `"stream": true` — вона довга.
